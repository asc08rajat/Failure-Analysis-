# RCA Report

## test_01_case_device_monitoring[3-disabled]

**Exception Type:** ElementNotInteractableException  
**Module:** device_monitoring  
**Repo Path:** tests/app/device_monitoring/test_device_monitoring_1.py  

**Root Cause:**  
The 'disabled' scenario attempts to work with a disabled control. FakeWebDriver raises ElementNotInteractableException during find_element for a disabled target, and the test does not anticipate or assert this state.

**Evidence:**  
- Exception message: Element not interactable: css=disabled-button url=https://example.test/app/device_monitoring  
- Traceback: tests/app/device_monitoring/test_device_monitoring_1.py:31 → el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)  
- Traceback: framework/fake_webdriver.py:34 → raise ElementNotInteractableException(...)  
- Relevant code snippet:
    elif case_id == "disabled":
        el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
        el.click()

**Suggested Fix Summary:**  
Treat the disabled path as a negative scenario and assert the expected ElementNotInteractableException using pytest.raises.

**Suggested Patch:**  
```diff
--- a/tests/app/device_monitoring/test_device_monitoring_1.py
+++ b/tests/app/device_monitoring/test_device_monitoring_1.py
@@
-    elif case_id == "disabled":
-        el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
-        el.click()
+    elif case_id == "disabled":
+        with pytest.raises(ElementNotInteractableException):
+            driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
```
