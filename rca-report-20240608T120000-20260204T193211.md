# RCA Report

## test_01_case_device_monitoring[3-disabled]

**Exception Type:** ElementNotInteractableException  
**Module:** device_monitoring  
**Repo Path:** tests/app/device_monitoring/test_device_monitoring_1.py  

**Root Cause:**  
The test attempts to interact with a button that is disabled, leading to an ElementNotInteractableException. The test does not check if the element is enabled before clicking.

**Evidence:**  
- Exception: ElementNotInteractableException at test_device_monitoring_1.py:31  
- Operation: find_element(css=disabled-button)  
- Relevant code:
        elif mode == "disabled":
            el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
            driver.click(el)

**Suggested Fix Summary:**  
Check if the element is enabled before attempting to click it to avoid interacting with disabled elements.

**Suggested Patch:**  
```diff
--- tests/app/device_monitoring/test_device_monitoring_1.py
+++ tests/app/device_monitoring/test_device_monitoring_1.py
@@ def test_01_case_device_monitoring(self, driver, case_id, mode):
-        elif mode == "disabled":
-            el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
-            driver.click(el)
+        elif mode == "disabled":
+            el = driver.find_element(Locator("css", "disabled-button"), timeout_s=10)
+            if hasattr(el, 'is_enabled') and not el.is_enabled():
+                pytest.skip("Button is disabled, skipping interaction.")
+            driver.click(el)
```
