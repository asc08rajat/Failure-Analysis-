## test_01_case_device_monitoring[3-disabled]

**Exception Type:** ElementNotInteractableException  
**Module:** device_monitoring  
**Repo Path:** tests/app/device_monitoring/test_device_monitoring_1.py  

**Root Cause:**  
The test clicks a button after only waiting for its presence, not for it to be enabled/clickable. In the 'disabled' scenario, the element is present but not interactable, causing ElementNotInteractableException on click.

**Evidence:**  
- ElementNotInteractableException at test_device_monitoring_1.py:31; find_element(css=disabled-button)  
- Test code uses presence wait and then clicks:
  disabled_btn = wait.until(EC.presence_of_element_located((By.CSS_SELECTOR, "disabled-button")))
  disabled_btn.click()  
- Single short timeout: wait = WebDriverWait(self.driver, 3) does not include clickability check.

**Suggested Fix Summary:**  
Avoid clicking when the scenario indicates 'disabled' and otherwise wait for the element to be clickable before clicking.

**Suggested Patch:**

 from selenium.webdriver.support import expected_conditions as EC

-
-        # Wait for a slow element to appear
