# Exception Insights

**Exception Type:** NoSuchElementException  
**Description:**  
An expected UI element was not found in the DOM at the time of interaction.  
**Most Likely Causes:**  
- Element selector is incorrect or outdated  
- Element is not rendered due to page state or timing issues  
- Element is inside an iframe or shadow DOM not handled  
**Resolution:**  
Verify selector accuracy, ensure element is present and visible before interaction, and handle dynamic content loading.  

---

**Exception Type:** ElementNotInteractableException  
**Description:**  
A UI element exists in the DOM but cannot be interacted with (e.g., not visible or disabled).  
**Most Likely Causes:**  
- Element is hidden or disabled  
- Timing issues cause element to not be ready  
- Overlapping elements block interaction  
**Resolution:**  
Ensure element is visible, enabled, and ready for interaction before performing actions.  

---

**Exception Type:** AssertionError  
**Description:**  
A test assertion failed because the expected and actual values did not match.  
**Most Likely Causes:**  
- Incorrect test expectations  
- Application under test has a defect  
- Test data or environment inconsistency  
**Resolution:**  
Review assertion logic, validate test data, and confirm application behavior aligns with requirements.  

---

**Exception Type:** WebDriverException  
**Description:**  
A generic error occurred in the WebDriver during browser automation.  
**Most Likely Causes:**  
- WebDriver or browser crash  
- Driver version incompatibility  
- Unexpected browser state  
**Resolution:**  
Check WebDriver and browser versions, review logs for details, and ensure environment stability.  

---

**Exception Type:** TimeoutException  
**Description:**  
An operation exceeded the allotted time to complete.  
**Most Likely Causes:**  
- Slow application response  
- Network latency or instability  
- Incorrect wait conditions  
**Resolution:**  
Increase timeout values, optimize application performance, and ensure proper synchronization.
