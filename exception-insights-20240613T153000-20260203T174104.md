# Exception Insights

**Exception Type:** NoSuchElementException  
**Description:**  
An expected UI element was not found in the DOM.  
**Most Likely Causes:**  
- Incorrect selector used  
- Element not rendered yet  
- Element removed from DOM  
**Resolution:**  
Verify selectors and ensure elements are present before interaction.  

---

**Exception Type:** ElementNotInteractableException  
**Description:**  
An element exists but cannot be interacted with (e.g., not visible or disabled).  
**Most Likely Causes:**  
- Element is hidden or disabled  
- Timing issues in UI rendering  
- Incorrect interaction method  
**Resolution:**  
Ensure the element is visible and enabled before attempting interaction.  

---

**Exception Type:** AssertionError  
**Description:**  
A test assertion failed, indicating an unexpected value or state.  
**Most Likely Causes:**  
- Incorrect expected value  
- Application bug  
- Test logic error  
**Resolution:**  
Review assertion logic and expected values; investigate application state.  

---

**Exception Type:** WebDriverException  
**Description:**  
A generic error occurred in the WebDriver during automation.  
**Most Likely Causes:**  
- Driver/browser incompatibility  
- WebDriver session lost  
- Automation environment misconfiguration  
**Resolution:**  
Check WebDriver setup, browser compatibility, and session management.  

---

**Exception Type:** TimeoutException  
**Description:**  
An operation exceeded the allotted time limit.  
**Most Likely Causes:**  
- Slow application response  
- Network latency  
- Incorrect timeout settings  
**Resolution:**  
Increase timeout values or optimize application/network performance.
